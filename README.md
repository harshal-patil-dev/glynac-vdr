# Glynac VDR

A responsive Virtual Data Room (VDR) frontend built as part of the Springer Capital Frontend Development Internship.

## Project Overview

Glynac VDR is a document management interface for organizing, searching, sorting, and previewing documents in an enterprise-style workspace.

## Tech Stack

- Next.js (App Router)
- React
- TypeScript
- Tailwind CSS
- Lucide React

## Features

- VDR dashboard with document binders
- Folder navigation and breadcrumbs
- Document search and filtering
- Sortable document table
- Document previews for supported text, Markdown, PDF, image, and JSON files
- New Folder interface
- Upload File interface
- Responsive user interface

## Getting Started

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

Open http://localhost:3000 in your browser.

### Validate the project

```bash
npm run lint
npm run build
```

## Current Scope

This is a frontend prototype using mock data and client-side state. Persistent storage, backend integration, real document storage, and production-grade access control are not yet implemented.
